# 🔵 AutoPulse Ford

## 🚗 Sobre o Projeto

O **AutoPulse Ford** é uma plataforma desenvolvida para transformar a experiência digital dos clientes Ford por meio de **monitoramento inteligente, análise automotiva e serviços conectados**.

A aplicação centraliza informações importantes sobre o veículo e oferece recursos para acompanhamento da saúde automotiva, manutenção preventiva, controle de gastos, alertas inteligentes e assistência virtual.

O objetivo é proporcionar ao motorista uma experiência mais **conectada, preventiva e inteligente**, facilitando o acesso às principais informações relacionadas ao seu veículo em uma única aplicação.

---

## 🎯 Desafio Escolhido

O grupo escolheu o desafio relacionado à **experiência digital automotiva conectada**, identificando uma oportunidade de aproximar ainda mais o motorista do ecossistema Ford utilizando **tecnologia, dados e inteligência artificial**.

Atualmente, informações relacionadas à manutenção, consumo, gastos e condições do veículo podem estar distribuídas entre diferentes serviços e sistemas.

O **AutoPulse** busca centralizar essas informações e transformá-las em dados úteis para o motorista, permitindo uma experiência mais simples e eficiente.

A solução foi desenvolvida pensando principalmente na utilização mobile, permitindo que o usuário consulte rapidamente informações importantes sobre seu veículo.

---

# ✨ Funcionalidades Implementadas

O AutoPulse conta com diferentes funcionalidades voltadas para acompanhamento e gerenciamento do veículo:

- 🚗 Monitoramento da saúde do veículo
- 🔧 Diagnóstico e manutenção preventiva
- 🚨 Sistema de alertas inteligentes
- ⛽ Registro de abastecimentos
- 💰 Histórico de despesas automotivas
- 🤖 Assistente virtual especializado em veículos Ford
- 📊 Análise de informações do veículo
- 🆚 Comparativo entre modelos Ford e concorrentes
- 📱 Interface responsiva para dispositivos móveis
- 🧭 Navegação organizada entre diferentes áreas da aplicação
- 🔵 Experiência integrada ao ecossistema Ford

---

# 🤖 Inteligência Artificial

Um dos principais diferenciais do AutoPulse é a utilização de **Inteligência Artificial como assistente automotivo**.

O assistente foi desenvolvido para auxiliar o motorista com dúvidas relacionadas aos veículos Ford e informações automotivas.

Entre suas possibilidades de utilização estão:

- esclarecer dúvidas sobre veículos Ford;
- consultar características e tecnologias dos modelos;
- auxiliar na interpretação de informações automotivas;
- fornecer orientações relacionadas ao uso do veículo;
- tornar a consulta de informações mais rápida e acessível.

A proposta é utilizar a IA como uma camada adicional de interação entre o motorista e as informações disponíveis dentro do AutoPulse.

# 🎨 Design System

A identidade visual do AutoPulse foi desenvolvida com foco em uma experiência **automotiva, tecnológica e moderna**, mantendo referências visuais relacionadas à identidade da Ford.

## 🎨 Paleta de cores

A interface utiliza principalmente tons de:

- 🔵 Azul — cor predominante da aplicação
- 🔷 Azul escuro — fundos, cards e áreas de destaque
- ⚪ Branco — textos e elementos de contraste
- ⚫ Tons escuros — fundos e componentes secundários
- 🟢 Verde — indicadores positivos e condições adequadas
- 🟡 Amarelo — atenção e manutenção preventiva
- 🔴 Vermelho — alertas e situações que exigem atenção

As cores dos indicadores também ajudam o usuário a identificar rapidamente o estado dos componentes do veículo.

## 🔤 Tipografia

A aplicação utiliza uma tipografia moderna e de fácil leitura, priorizando:

- títulos com maior destaque;
- informações importantes em negrito;
- textos secundários com menor peso visual;
- hierarquia clara entre títulos, informações e descrições.

## 🧩 Componentes

A interface utiliza componentes visuais padronizados, como:

- Cards
- Botões
- Indicadores de status
- Alertas
- Ícones
- Campos de formulário
- Elementos de navegação
- Indicadores de saúde do veículo

Essa padronização mantém consistência entre as diferentes telas da aplicação.

## 📱 Responsividade

A interface foi desenvolvida com foco em dispositivos móveis, adaptando seus elementos para diferentes tamanhos de tela e mantendo boa legibilidade e usabilidade.

# 🧠 Decisões Técnicas

## React + TypeScript

O projeto utiliza **React com TypeScript**, permitindo criar uma aplicação baseada em componentes reutilizáveis e facilitando a organização e manutenção do código.

O TypeScript também adiciona tipagem ao projeto, reduzindo possíveis erros durante o desenvolvimento.

## Vite

O **Vite** foi utilizado como ferramenta de desenvolvimento e build devido à sua velocidade de inicialização e configuração simplificada.

## React Router

O **React Router** é responsável pela navegação entre as diferentes áreas do AutoPulse, permitindo organizar a aplicação em páginas independentes.

## Tailwind CSS

O **Tailwind CSS** foi utilizado para construção da interface e do Design System, facilitando a criação de layouts responsivos e mantendo consistência visual entre os componentes.

## Componentização

A aplicação foi estruturada utilizando componentes reutilizáveis, evitando repetição de código e facilitando futuras evoluções do projeto.

# 🏗️ Estrutura do Projeto

O código foi organizado de maneira modular para facilitar manutenção e evolução da aplicação.

```text
src/
├── assets/
├── components/
├── context/
├── data/
├── pages/
├── types/
└── utils/
```

### 📁 assets

Armazena imagens e recursos visuais utilizados pela aplicação.

### 📁 components

Contém componentes reutilizáveis utilizados em diferentes páginas.

### 📁 context

Responsável pelo gerenciamento de estados e informações compartilhadas entre diferentes partes da aplicação.

### 📁 data

Contém dados utilizados pela aplicação.

### 📁 pages

Contém as principais telas do AutoPulse.

### 📁 types

Centraliza definições e interfaces TypeScript.

### 📁 utils

Contém funções auxiliares utilizadas pelo sistema.

# ⚙️ Como executar o projeto

## 1. Clone o repositório

```bash
git clone https://github.com/AndreLQueiroz/aplicativo-ford-3-0.git
```

## 2. Entre na pasta

```bash
cd aplicativo-ford-3-0
```

## 3. Instale as dependências

```bash
npm install
```

## 4. Execute o projeto

```bash
npm run dev
```

Após iniciar o servidor, acesse no navegador o endereço informado pelo Vite.

> Algumas funcionalidades que utilizam serviços externos podem exigir configuração de variáveis de ambiente.
